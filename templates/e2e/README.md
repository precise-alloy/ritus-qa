# E2E test suite (Playwright)

Generated by the ritus-qa plugin. Page Object pattern, 2 layers:

- `page_interfaces/` — selectors only (`static readonly`, `%s` placeholders for dynamic values)
- `page_objects/` — actions, extend `commons/BasePage.ts`

## Setup

```powershell
cp .env.example .env   # fill in TEST_BASE_URL, CMS_EMAIL, CMS_PASSWORD
npm install
npx playwright install
```

## Run

```powershell
npx playwright test --project smoke       # quick smoke
npx playwright test --project regression  # full regression
npx playwright test --project cms         # CMS edit-mode (logs in via e2e_tests/cms/auth.setup.ts)
npx playwright test --project visual      # visual snapshots
npm run report                            # open the HTML report
```

## Conventions

- One spec per page/feature under `e2e_tests/<scope>/<Page>.spec.ts`.
- New page → add `page_interfaces/specific/XPageUI.ts` (selectors) + `page_objects/specific/XPage.ts` (actions).
- Shared selectors/actions live in `page_interfaces/commons` / `page_objects/commons`.
- Test data per page lives in `test-data/XPageTestData.ts`.
- Never commit `.env` or `auth/*.json` (both git-ignored).
